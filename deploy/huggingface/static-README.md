# Recommendation Engine

Pick a user, see the ten films a TensorFlow model ranks first for them, and read how it scores against a standard SVD baseline.

This demo shows saved answers from the model's API, so it runs without a server and never sleeps. The live API, the training code and the results are in the repository:

https://github.com/Onkar-Gupta/recommendation-engine
