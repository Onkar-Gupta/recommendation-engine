# Recommendation Engine

Pick a user, see the ten films a TensorFlow model ranks first for them, and read how it scores against a standard SVD baseline.

The model is trained on MovieLens 100K when this Space builds. The free tier sleeps after a period with no visitors, so the first load can take about a minute.

Source code, results and documentation: https://github.com/Onkar-Gupta/recommendation-engine
